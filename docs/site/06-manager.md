# Руководителю

Руководитель смотрит, где сервис теряет качество, какие риски найдены, чему учить сотрудников и что менять в процессах. Для этого есть экран «Аналитика» и отчёт для руководства, который открывается в браузере и печатается.

## Экран «Аналитика»

Экран открывается в меню «Аналитика» (`#/analytics`). Каждое число ведёт к списку диалогов, из списка — к карточке и реплике.

### Четыре вопроса бизнеса

| Плитка | Что показывает | Куда ведёт |
| --- | --- | --- |
| Качество сервиса | Сколько запросов остались без решения или понятного следующего шага | Очередь, группа «Без следующего шага» |
| Контроль рисков | Сколько разговоров с грубыми ошибками и сколько из них проверено | Очередь, группа «Грубые ошибки» |
| Развитие сотрудников | Критерий, на котором чаще всего теряют баллы | Экран «Обучение» |
| Улучшение процессов | Самая частая причина снижения | Таблица «Повторяющиеся причины» |

### Таблицы

- «Результат по критериям» — для каждого критерия: вес, сколько оценок применимо, сколько N/A, результат (доля «Да» или средняя ступень шкалы) и сколько разговоров теряют баллы. Где применимых меньше пяти, стоит пометка «мало данных».
- «Критерий и язык» — сколько применимых разговоров потеряли баллы, по языкам RU, KZ, EN. В ячейке число, а не только цвет: на малых выборках процент обманчив.
- «Грубые ошибки по видам» — число разговоров по каждому виду нарушения и сколько проверено.
- «Качество самой оценки» — совпадение двух моделей (если включено второе мнение) или число ответов без найденной цитаты, сколько ответов ждут решения специалиста, сколько апелляций и проверок изменили оценку.
- «Где модель расходится с людьми» — решения по критериям и языкам: сколько решено и сколько изменено.
- «Повторяющиеся причины» — причины снижения, сгруппированные по точной формулировке: число разговоров, критерии, языки и примеры.

### Кому исправлять причину

В таблице «Повторяющиеся причины» колонка «Что менять» назначает адресата: «Инструкция», «Сервис», «Продукт» или «Не назначено». Решение принимает человек, значение сохраняется на сервере и попадает в отчёт.

### Выгрузки

- «Скачать CSV» — повторяющиеся причины (`cqa-reasons.csv`).
- «Скачать итоги» — итог и ответы по критериям для каждого диалога (`cqa-results.csv`).

Оба файла в кодировке UTF-8 с разделителем `;` и открываются в Excel.

Оценки для Excel можно забрать и с сервера, без интерфейса: `/api/scores/export` — строка на диалог (итог, грубые нарушения, нужна ли проверка, проверен ли, ответ по каждому критерию), `/api/scores/export?shape=long` — строка на пару «диалог — критерий» с ответом, обоснованием, репликами-основаниями и решением проверяющего. Фильтры `lang` и `ch` — как у отчёта ниже. Ответы учитывают последнее решение, итог совпадает с карточкой.

Трендов по неделям нет: в данных организаторов нет дат чатов.

## Отчёт для руководства

Отчёт собирается сервером из того же состояния, что видит интерфейс, без вызова модели. Ссылки на него в меню нет: откройте адрес в браузере.

| Адрес | Формат | Для чего |
| --- | --- | --- |
| `/api/report` | HTML, страница A4 | Просмотр и печать, кнопка «Печать / PDF» |
| `/api/report?format=md` | Markdown | Вики, почта |
| `/api/report?format=json` | JSON | Свои дашборды и аналитика |

Например, на локальном сервере: `http://127.0.0.1:8000/api/report`.

Фильтры необязательны и сочетаются с любым форматом:

- `lang=RU` (или `KZ`, `EN`) — только диалоги на этом языке;
- `ch=chat` или `ch=call` — только чаты или только звонки.

Пример: `/api/report?ch=call&lang=RU` — отчёт по звонкам на русском языке.

### Что в отчёте

- «Главное» — 3–5 выводов по-русски, посчитанных из чисел.
- «Ключевые числа» — средний итог, доля разговоров с грубыми нарушениями, доля без следующего шага, сколько диалогов ждут проверки, апелляции на рассмотрении, средняя стоимость и время оценки одного диалога.
- Таблицы: грубые нарушения по видам, результат по критериям, причины потери баллов (топ-10) с адресатом «Что менять», результаты по каналам и языкам.

Итог в отчёте учитывает решения по апелляциям и проверкам. Грубые нарушения в итог не входят. Если оценённых диалогов нет, отчёт пишет «Нет оценённых диалогов».

### Печать

1. Откройте `/api/report` в браузере.
2. Нажмите «Печать / PDF» в правом верхнем углу страницы.
3. Выберите принтер или «Сохранить как PDF».

Страница самодостаточна: стили внутри, внешних ссылок и скриптов нет. Полоски в таблицах печатаются без дополнительных настроек браузера.

## Стоимость и время оценки

- В карточке разговора внизу — строка «Оценка: …»: число вызовов основной модели, запросов второго мнения, время и цена последней оценки диалога.
- На экране «Диалоги» панель оценки показывает суммарное число вызовов и стоимость по набору, а во время запуска — оставшееся время.
- В отчёте — средняя стоимость и время на диалог.

Цена считается по тарифам из настроек сервера. Если тариф не задан, в долларах цена не считается, но вызовы и время видны всегда.

Отдельный экран для разбора с сотрудником — «Обучение», см. [Руководство оператора](operator).

## Скоро

- Оценки по сотрудникам: средний итог и потери по каждому оператору.
- Сравнение запусков: разница ответов и итогов между двумя оценками одного набора.
