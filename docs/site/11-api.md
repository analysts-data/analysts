# Справочник API

Справочник строится при открытии страницы из схемы OpenAPI работающего сервера, поэтому всегда совпадает с кодом. Схема в машинном виде — `GET /api/openapi.json`. Сценарии с примерами на curl и Python — [Интеграция по API](integration).

Для каждого метода указаны назначение, параметры пути и запроса, поля тела с примером и коды ответов. Типы моделей ведут в раздел «Схемы данных» в конце страницы. Примеры curl рассчитаны на сервер по адресу `http://127.0.0.1:8000`; `@body.json` — файл с телом запроса, как в примере выше него.

Ответы многих методов в схеме помечены как `object`: их форма описана в описании метода и в сценариях интеграции. Ошибки приходят с телом `{"detail": "..."}`, коды — в разделе [«Коды ответов и ошибки»](integration#коды-ответов-и-ошибки).
