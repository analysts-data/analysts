# Быстрый старт

Нужны Python 3.12 и менеджер пакетов `uv`. Для панели «Интонация» у звонков нужен системный `ffmpeg`. Все команды выполняются из корня репозитория.

## Посмотреть без ключа: make demo

```bash
uv sync
make demo
```

`make demo` поднимает сервер на `http://127.0.0.1:8000` и работает без сети и без ключа модели:

- ответы модели берутся из записей (`CQA_LLM_MODE=replay`, каталог `tests/cassettes`);
- используется отдельная база `data/demo.db`, рабочая база не меняется;
- загружается синтетический набор защиты `tests/e2e/fixtures/defence_set.json` (8 диалогов, включая звонок) и сразу оценивается.

Откройте в браузере очередь, карточку разговора с основаниями, апелляции, аналитику и обучение. Документация — `http://127.0.0.1:8000/docs/`.

Если записанных ответов нет, `make demo` останавливается с подсказкой: их пишет `make record` с ключом модели в `.env` и только на синтетических данных.

## Рабочий запуск: make run

```bash
uv sync
cp .env.example .env   # заполните нужные CQA_*
make run               # http://127.0.0.1:8000
```

`make run` запускает сервер с перезагрузкой при изменении кода. База по умолчанию — `data/cqa.db`; при первом запуске в неё записывается начальная версия чек-листа.

## Настройка .env

Все настройки — переменные `CQA_*` в файле `.env` или в окружении. Пустое значение берёт умолчание из `src/cqa/settings.py`. Файл `.env` в репозиторий не попадает.

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `CQA_LLM_MODE` | `replay` | `replay` — записанные ответы без сети, `live` — живая модель, `record` — живая модель с записью ответов |
| `CQA_LLM_BASE_URL`, `CQA_LLM_API_KEY` | пусто | Адрес OpenAI-совместимого API и ключ основной модели |
| `CQA_LLM_MODEL` | `qwen3-6` | Имя модели у провайдера |
| `CQA_LLM_PROFILE` | `plain` | Параметры запросов: `plain` или `deepseek` |
| `CQA_LLM_REASONING` | `on` | `on` — рассуждение модели, `off` — строгий JSON |
| `CQA_LLM_MAX_PARALLEL` | `4` | Сколько запросов к модели идёт одновременно |
| `CQA_LLM_RPM` | `120` | Лимит запросов в минуту, `0` — без лимита |
| `CQA_LLM_TIMEOUT_S` | `180` | Таймаут запроса к модели, секунды |
| `CQA_LLM_PRICE_IN`, `CQA_LLM_PRICE_OUT` | `0` | Цена за 1 млн токенов, USD; `0` — цена не считается |
| `CQA_VERIFIER` | пусто | Второе мнение: `jev` или код провайдера |
| `CQA_EVALUATOR` | `llm` | `jev` — режим «Только Jev» |
| `CQA_JEV_API_KEY` | пусто | Ключ Jev (TypeSafe) |
| `CQA_OPENROUTER_API_KEY` | пусто | Ключ встроенного провайдера Jev Router через OpenRouter |
| `CQA_ANONYMIZE` | включено | Обезличивание до отправки модели |
| `CQA_DATA_WHERE` | `kz` | Где обрабатываются данные: `kz`, `local`, `external` (плашка в шапке) |
| `CQA_ALLOW_REAL_DATA` | выключено | Разрешает отправку реальных звонков в модель. Ставит только человек |
| `CQA_ORG_API_URL` | пусто | Адрес API источника наборов; пусто — наборы только файлом или ссылкой из интерфейса |
| `CQA_DB_PATH` | `data/cqa.db` | Файл базы SQLite |

Готовые профили лежат комментариями в `.env.example`: сценарий 4 — модель у провайдера в Казахстане (основной), сценарий 5 — запасной внешний провайдер со вторым мнением Jev, сценарий 6 — локальная модель.

Режим, провайдеры и ключи можно поменять и в интерфейсе, в окне режима: значения сохраняются в базе поверх `.env` и переживают перезапуск.

## Локальная модель

Любой OpenAI-совместимый сервер (Ollama, vLLM, LM Studio) подключается теми же переменными:

```bash
CQA_LLM_MODE=live \
CQA_LLM_BASE_URL=http://localhost:11434/v1 \
CQA_LLM_MODEL=<имя модели на сервере> \
CQA_LLM_API_KEY=local \
CQA_DATA_WHERE=local \
make run
```

Серверу ключ не нужен, но проверка конфигурации требует непустой `CQA_LLM_API_KEY` — подойдёт любая строка. Обезличивание остаётся включённым, реплики не покидают машину.

## ffmpeg и интонация

Praat устанавливается вместе с зависимостями (`uv sync`, пакет `praat-parselmouth`), `ffmpeg` ставится отдельно и должен быть в `PATH`:

```bash
brew install ffmpeg        # macOS
sudo apt install ffmpeg    # Debian, Ubuntu
```

Без `ffmpeg` панель «Интонация» в карточке звонка показывает «Интонация недоступна» (сервер отвечает 502), остальное работает, оценка звонка идёт без сводки по звуку.

## Первые шаги в интерфейсе

1. Откройте `http://127.0.0.1:8000`.
2. На экране «Диалоги» загрузите набор: «Получить набор» по `group_id`, «Загрузить JSON» файлом или «Вставить диалог» текстом.
3. Нажмите «Оценить»: видимые диалоги оцениваются в порядке очереди, прогресс, время до конца и цена видны сразу.
4. Откройте диалог: итог, «Как посчитан итог», главные потери с обоснованием и репликой-основанием.

Подробно по ролям — [Руководство специалиста КК](qa-specialist), [Руководство оператора](operator), [Руководство проверяющего](reviewer), [Руководителю](manager).

