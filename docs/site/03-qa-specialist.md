# Руководство специалиста КК

Специалист контроля качества загружает диалоги, запускает оценку моделью, проверяет спорные ответы, ставит ручные оценки и ведёт чек-лист. Все действия этого раздела доступны в роли «Специалист КК»: переключатель ролей находится в шапке справа. Командная палитра (Ctrl+K, на Mac ⌘K) находит диалог по номеру или названию и открывает экраны и частые действия. В ролях «Оператор» и «Проверяющий» кнопки загрузки, оценки и редактирования скрыты.

## Экран «Диалоги»

Экран открывается по адресу `#/queue`; в роли «Специалист КК» он открывается по умолчанию. В шапке — кнопка «Добавить диалоги», ниже — панель «Оценка набора» и плитки-фильтры, затем таблица диалогов.

### Загрузка диалогов

Меню «Добавить диалоги»:

| Пункт | Что происходит |
| --- | --- |
| «Набор организаторов…» | Окно с полями «Код набора» (по умолчанию `DEV`) и «Ссылка API, необязательно». «Получить набор» загружает набор по коду. Если ссылка заполнена, сервер сохраняет её у себя и затем сам забирает этот набор раз в 5 минут; под заголовком появляется строка «Автосинхронизация … раз в 5 минут». |
| «Файл JSON…» | Файл в формате ответа API организаторов загружается как есть. |
| «Вставить текст диалога…» | Окно «Вставить диалог» с полями «Название», «Канал» (чат или звонок) и «Текст диалога». |

Повторные диалоги с тем же идентификатором пропускаются. Оценка после загрузки сама не запускается.

### Вставка диалога текстом

1. В меню «Добавить диалоги» выберите «Вставить текст диалога…».
2. Введите название и выберите канал.
3. Вставьте текст: каждая реплика — строка вида `Клиент: …`, `Оператор: …`, `Бот: …` или `Система: …`. Строка без роли продолжает предыдущую реплику.
4. Нажмите «Сохранить». Карточка нового диалога откроется сразу.
5. В окне «Диалог добавлен» выберите «Оценить» или «Закрыть»: оценку можно запустить и позже из очереди.

Диалог без реплики оператора не сохраняется: сервер вернёт ошибку, текст останется в окне.

### Очередь и фильтры

Диалоги идут группами:

1. «Грубые ошибки» — флаг нарушения, диалог ещё не отмечен проверенным.
2. «Нужна проверка человека» — модели разошлись или цитата не нашлась в реплике (в режиме «Только Jev» — Jev не уверен в ответе).
3. «Без понятного следующего шага» — критерий с сигналом «Решение запроса» ниже верхней ступени.
4. «Остальные».

Внутри группы диалоги отсортированы по итогу по возрастанию. Колонка «Почему в очереди» называет причину, «Где потеряны баллы» — до трёх критериев с потерями, «Статус» — «Ждёт оценки», «Апелляция» или «Проверен».

Плитки «Грубые ошибки», «Нужна проверка» и «Без следующего шага» включают фильтр по группе, повторное нажатие снимает его. Плитка «Апелляции ждут решения» открывает экран апелляций, «Средний итог» — аналитику. Над таблицей есть поиск по номеру диалога и тексту реплик и списки «Язык» и «Канал»; если под фильтры ничего не подходит, появляется «Сбросить фильтры». Фильтры хранятся в адресе, например `#/queue?grp=risk&lang=KZ`, поэтому ссылку на выборку можно переслать коллеге.

Клавиши J и K перемещают выделение по списку, Enter открывает карточку, / ставит курсор в поиск.

## Оценка моделью

Панель «Оценка набора» показывает, сколько диалогов оценено по текущей версии чек-листа, число вызовов и стоимость.

- «Оценить» запускает оценку диалогов, видимых в таблице, в порядке очереди; если есть неоценённые, кнопка называет их число («Оценить N диалогов», с фильтром — «Оценить показанные: N»). Без фильтров оценивается весь набор.
- Во время оценки видна строка «Идёт оценка: оценено N из M ответов по критериям», число вызовов, стоимость и оставшееся время. «Остановить» прерывает запуск: диалоги в работе завершаются, новые не начинаются.
- Повторное «Оценить» продолжает с места остановки: готовые ответы не пересчитываются.
- Прогресс сохраняется после перезагрузки страницы: идущий запуск запоминается в браузере.
- Ошибки запуска выводятся рядом с прогрессом, список по диалогам раскрывается по «Показать ошибки (N)».

Модель оценивает только критерии без ответа. Ручные ответы она не меняет.

## Карточка разговора

Карточка открывается по адресу `#/d/<id>`. Ссылки «Предыдущий» и «Следующий» и клавиши J и K переходят по очереди.

### Сводка

- «Итог» — число из 100 и баллы по секциям. Раздел «Как посчитан итог» показывает набранные баллы из применимых, критерии с N/A и перераспределение их веса. Если часть критериев ждёт оценки, итог помечен как предварительный. Формула — в разделе [Чек-лист и расчёт итога](checklist).
- «Почему снижена оценка» — до трёх главных потерь с обоснованием и номером реплики. Нажатие переводит к критерию и подсвечивает реплику.
- «Грубые ошибки» — «Найдены: N» или «Не найдены», по каждому найденному виду причина, цитата и «К реплике N». Флаг на итог не влияет.
- Строка «Второе мнение совпало по N из M критериев» появляется, если второе мнение включено.

### Критерии и основания

Справа — критерии по секциям. Раскрытый критерий показывает ответ на шкале, обоснование, реплики-основания с кнопкой «К реплике» и, при потере баллов, блок «Как сказать лучше». Наведение на критерий подсвечивает его реплики в расшифровке, кнопка «Развернуть все обоснования» раскрывает все критерии сразу. Если реплик-оснований нет (действие пропущено), карточка пишет, какой участок проверен.

У звонка над расшифровкой — плеер и панель «Интонация», см. [Интонация звонка](intonation).

### Оценить моделью

Кнопка «Оценить моделью» в шапке карточки появляется, если у диалога есть критерии без ответа. Она запускает оценку только этого диалога.

### Ручной ответ

- У неоценённого критерия — «Оценить вручную».
- У оценённого — «Исправить оценку».

В окне выберите ответ из допустимых для критерия (для флага — отметьте найденные нарушения), при желании заполните «Обоснование, по желанию» и нажмите «Сохранить ответ». Ответ получает метку «Исправлено специалистом», итог пересчитывается сразу. Повторная оценка моделью ручной ответ не меняет, прежний ответ модели остаётся в базе. Пока по критерию есть апелляция или решение, кнопка «Исправить оценку» не показывается: решение важнее ответа.

### Нужна проверка: решения в карточке

Если второе мнение разошлось с основной моделью, в критерии появляется блок «Второе мнение: …» с кнопками «Оставить …» и «Принять …». Если цитата не нашлась в реплике или Jev не уверен в ответе — кнопки «Оставить …» и «Изменить». В окне решения («Оставить оценку модели», «Принять второе мнение» или «Изменить ответ») поле «Причина решения, обязательно» — не короче 5 символов. Решение сохраняется отдельной записью, исходный ответ модели не меняется, а в критерии появляется «История оценки».

### Отметить проверенным

«Отметить проверенным» убирает диалог из верхних групп очереди. «Снять отметку» возвращает его.

## Чек-лист

Редактор открывается на экране «Чек-лист» (`#/checklist`). Черновик — копия применяемой версии, правки живут в браузере до сохранения.

### Поля критерия

| Поле | Назначение |
| --- | --- |
| Название, Секция | Как критерий виден в карточке и аналитике. |
| Что проверяем | Текст, который модель получает дословно. |
| Уточнение для звонка | Необязательно. Модель получает его только на звонках, запрос по чатам не меняется. |
| Тип ответа | «Да / Нет», «Шкала» или «Грубая ошибка, без баллов». |
| Вес | Доля в итоге до перераспределения N/A. |
| «Может быть N/A (не применимо)», «Когда N/A» | Когда критерий неприменим. |
| Ступени шкалы | По строке на ступень: «балл: что значит». |
| Подвопросы | Для флага: по строке на вид нарушения. |
| Канал | «Все каналы», «Чат» или «Звонок». Для одного канала N/A включается автоматически. |
| Роль в отчётах | «Нет», «Решение запроса» или «Грубая ошибка»: на ней строятся группа «Без следующего шага» и плитки аналитики. |

В шапке экрана — «Импорт», «Экспорт», «Отменить изменения», «Что изменится», «Добавить критерий» и «Сохранить как vN». Рядом со списком критериев — «Сумма весов» и список версий. При несохранённых правках шапка показывает «Есть несохранённые изменения» и, если итоги изменятся, «Средний итог было → станет». Под редактором — поле «Общие правила»: модель получает их вместе с каждым критерием, поэтому их смена требует новой оценки всего чек-листа.

### Сохранение и версии

1. Внесите правки. Изменённые критерии помечены «изменён».
2. «Что изменится» покажет разницу черновика с текущей версией: что добавлено, изменено или удалено и что потребует новой оценки.
3. «Сохранить как vN» создаёт новую версию. Смена веса пересчитывает итоги без модели. Смена текста, типа, шкалы или N/A требует новой оценки этого критерия, смена уточнения для звонка — только на звонках.
4. Если критерии ждут оценки, появится баннер с кнопкой «Оценить набор».

«Отменить изменения» сбрасывает черновик. Апелляции на рассмотрении по удалённым критериям и по критериям, которые требуют новой оценки, закрываются со статусом «Закрыта». Смена веса апелляции не закрывает.

В списке версий у каждой прежней версии есть «Сравнить с текущей».

### Экспорт и импорт

- Меню «Экспорт»: выберите «Сохранённая версия» и формат — «JSON», «Excel (CSV)», «Markdown» или «Памятка для печати» (открывается во вкладке, формат A4). Там же «Экспорт в формат Jev» сохраняет вопросы для редактора Jev.
- Меню «Импорт»: «Импорт из файла чек-листа (JSON)» заменяет черновик, пункт недоступен, пока есть несохранённые правки; «Импорт из формата Jev» обновляет черновик по ID критериев, веса настраиваются отдельно.
- В ролях «Оператор» и «Проверяющий» чек-лист открывается только для просмотра и экспорта.

## Режим оценки

Плашка в шапке показывает, где обрабатываются данные, обезличены ли транскрипты, какая модель отвечает и включено ли второе мнение, например «Обработка: Казахстан · транскрипты обезличены · модель qwen3-6». В режиме записанных ответов вместо модели — «Записанные ответы». Нажатие на плашку в роли «Специалист КК» открывает окно «Режим оценки»:

- «Оценщик»: «Языковая модель» или «Только Jev (быстро, без обоснований)».
- «Модели OpenAI-формата · отметьте основную»: «Проверить связь», «Изменить», «Удалить» (у встроенной модели Jev Router — «Сбросить»), «Добавить модель».
- «Второе мнение», «Ключ Jev».
- «Обезличивать транскрипты перед отправкой модели» и «Разрешить отправлять модели реальные звонки».

Режим применяется сразу, без перезапуска сервера. Ключи хранятся на сервере и в браузер не возвращаются. Отключение обезличивания для внешнего API и разрешение реальных звонков требуют подтверждения. Подробнее — [Безопасность и данные](security).

## Владельцы причин

На экране «Аналитика» в таблице «Повторяющиеся причины» колонка «Кто исправляет» назначает адресата причины: «Инструкция», «Сервис» или «Продукт». Значение сохраняется на сервере и попадает в отчёт для руководства, см. [Руководителю](manager).
